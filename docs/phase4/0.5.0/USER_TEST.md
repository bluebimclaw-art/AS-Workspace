# 第④階段使用者驗收

先讀本輪 RESULTS.md 的實測與限制。Windows 隔離預覽預計在 `http://127.0.0.1:4319/`；僅限本機，沒有改 Mac 的4317。合成帳戶資料放在本機 `config/phase4-test-access.local.json`，不隨 GitHub 或部署 ZIP 發布。正式 Mac 用新資料夾／獨立資料建立自己的帳戶。

## WordCraft

1. 登入 member，按左邊 WordCraft。應看到完整 ribbon 及頁面編輯器。
2. 在共用下拉選一份 DOCX，開啟。新增中文、粗體及小表格，Save 或 Ctrl+S。
3. 應出現「已保存…vN」；關閉並釋放，再開啟，文字及表格保留。未保存時按其他功能，應被攔截而保留內容。
4. 到「背景處理及範本」建立報價單或事故報告。範本只含待填欄位，需自行填資料，不應出現編造價格或事故事實。
5. 選「轉出 PDF 及 DOCX 副本」，勾選已保存版本，提交。任務可見 queued/running/succeeded 或具體失敗，輸出自動出現在共用項目檔案。
6. 下載 DOCX / PDF，核對內容、表格及中文。試一份公司的實際文件，記錄圖表、頁碼、字型、註解或修訂是否保持；不要把合成文件通過當成實際檔案已相容。

## PdfCraft

1. 左邊 PdfCraft，選一份共用 PDF，開啟完整工具介面。中文檔名應可讀。
2. 用 Organize pages 旋轉一頁，Save。應保存為同一檔的新版本；重開後方向保留，舊版本仍可下載。
3. 在背景處理選兩份 PDF，依勾選順序合併。核對頁數及順序。
4. 抽頁、分拆、刪頁、倒序各試一次；所有結果應是新檔，原檔及原版本不變。
5. 試錯頁碼，應明確失敗，不產生錯誤結果；之後正確任務仍可執行。
6. 「優化」不保證變小：如工具沒有較小結果，應清楚顯示未壓縮，不能當作成功縮小。

## 共用權限、版本、AI 與隊列

1. 用另一個 Chrome profile／無痕視窗登入第二個 member。第一人開著文件時，第二人不能取得同檔編輯鎖；第一人關閉並釋放後，第二人可重開最新版本。
2. viewer 可讀取／下載共用檔案，不能編輯、上載、索引、還原或提交 Office／AI 任務。
3. 成員先按「讀取供搜尋／AI」並完成任務，再開右邊 AI 助手。只會使用已保存、已索引版本；未保存內容不應被說成已讀。
4. AI 及 Office 共用 FIFO，兩帳戶提交後觀察 running/queued 及先後完成。模型仍在左下選擇；本機示範端點未接真實模型，若要生成需另用公司批准的設定，不更改 Hermes。
5. 關閉未執行的任務應取消；處理失敗、重啟後 interrupted 均需明確顯示，不能默默重送。

共用保存單檔5MB。OCR 模型／掃描件、大型複雜文件、數碼簽章、郵件合併、所有上游功能及 Mac 新版仍需另外驗收。若失敗，記錄版本、操作、原檔類型及可重現樣本；先不要把真實公司文件上傳 GitHub。
