# AS Workspace v0.6.0 使用者驗收

以 Windows 本機合成帳戶開始；Mac 帳戶及舊平台保持原樣。測試期間不要輸入正式公司機密。測試模型未接通時，AI 預期顯示失敗，不能當成真實推理驗收。

1. 登入頁、頁籤標題及側欄顯示 AS Workspace。開 DeckCraft，見真正的多頁編輯器。
2. 從共用檔案開啟 PPTX，修改中文字、加頁及形狀。按 Save，看到平台成功通知及版本遞增；關閉並重開驗證。
3. 不保存先換功能應被阻止。保存失敗時，編輯器內容保留，可重試、另存副本或下載備份。5MB 以上不可悄悄丟棄。
4. 背景起草輸入「每張第一行標題、其餘內文」，獨立一行 `---` 分隔。應輸出多頁 PPTX及 PDF 到同一檔案庫，不覆寫原檔。
5. 選簡報「讀取供搜尋／AI」；以第二張獨有詞搜尋，應帶第2張及版本。AI 只讀已索引的保存版本，模型由左下選擇。
6. 第二 member 嘗試同檔編輯應遇到鎖定／409；兩帳戶提交 AI及 Office 共用 FIFO，請勿把模擬模型當真實 Ollama。
7. viewer 應只能下載及閱讀對應保存版本 PDF，不能編輯、索引或提交任務。
8. 回歸 Word、PDF、Grid及 Excalidraw；所有原版本應保留。實際下載後核對 hash；下載診斷不可當作瀏覽器已保存。

動畫、影音、複雜 PowerPoint、巨型圖片、完整字型與 Safari 需另外驗收。
