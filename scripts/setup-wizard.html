1 · 安裝位置

建立獨立新平台。程式與資料目錄必須空白；套件安裝需要已批准的 npm registry 網絡。這個版本需先有 Node 22.22.3+，建議使用已驗證的 Node 24。

建議公司將資料放在已批准的本機資料磁碟。平台備份不包含外部搜尋來源檔案。

不自動修改防火牆或系統信任。LAN使用者須核對公開CA指紋並完成信任；未經另一部電腦驗證，不代表跨機可用。

3 · 首次管理員

只供新資料目錄首次建立。現有帳戶必須在平台Admin管理。

沒有本地LLM也可以安裝。Hermes若轉用雲端，仍須按雲端資料政策處理。只偵測指定本機端點；不讀取Hermes金鑰或OAuth檔案。
